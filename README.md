## 📖 Overview

This repository hosts a curated collection of iCalendar (`.ics`) files, providing direct subscriptions to schedules for major CS2, Rainbow Six, UFC, and Top14 events. By subscribing to these feeds, you can keep track of all upcoming matches and tournaments directly within your personal calendar app (Apple Calendar, Google Calendar, Outlook, etc.).

## 🏆 Available Feeds

- **CS2 Tier 1 Events** (`cs2-tier1-2026.ics`)
- **BLAST Open Rotterdam 2026** (`blast-open-rotterdam-2026.ics`)
- **Rainbow Six Tier 1 Events** (`r6-tier1-2026.ics`)
- **UFC Announced Fights** (`ufc-announced.ics`)
- **Top 14 Rugby** (`top14-2026.ics`)
- **UBB Only** (`ubb-only.ics`)

## ✨ Features

- 🔄 **Automated Updates**: Feeds are designed to stay in sync with live scheduling changes.
- 📱 **Cross-Platform Compatibility**: Works flawlessly with Google Calendar, Apple Calendar, Outlook, and any standard calendar client.
- 🚀 **Zero Friction Setup**: No software required, just copy the URL and subscribe.

## 🚀 Setup / Installation

To add a calendar feed to your personal calendar:

1. Browse the files in this repository and click on the `.ics` file you want.
2. Click the **"Raw"** button in the top right to get the direct file URL.
3. Open your calendar application:
   - **Google Calendar**: Click the `+` next to "Other calendars" > "From URL" > Paste the Raw URL.
   - **Apple Calendar**: File > New Calendar Subscription > Paste the Raw URL.
   - **Outlook**: Add Calendar > Subscribe from web > Paste the Raw URL.
4. Set the auto-refresh interval (we recommend daily) and save!
